困っていることがあるときは、先に よくある質問 を見ると早いかもしれません。

01

撮影画面の見かた

  1. 情報帯。1行目は露出モード・シャッター速度・ISO・露出補正・ホワイトバランス。2行目は、いま効いているルック・合成・HDR・ボケ・透かし・フラッシュ・画質です。設定を開かなくても、いまの状態がここで分かります。タップすると露出の設定が開きます。
  2. プレビュー。仕上がりに近い絵が出ます。ルックやボケを変えると、この場で見た目が変わります。ピントを合わせたいところをタップしてください。
  3. ルック。色の方向性を選びます（21種類）。
  4. 撮影補助。合成・HDR・セルフタイマー・構図グリッド・水準器・動画。
  5. 設定。画質や保存形式など、じっくり決めるものはこちら。
  6. 直前の1枚。タップすると、撮った写真をアプリの中で見られます。
  7. シャッター。押すだけ。動画モードのときは赤い丸に変わります。

下の帯には左から ルック / 仕上げ / 露出 / フラッシュ / 撮影補助 / 設定 が並びます（表示モードが「標準」のとき）。 押すとその場で小さな面が開き、値を変えるとすぐプレビューに出ます。 シャッターの右にある「1x」はレンズの切り替えです。

表示モードを「かんたん」にすると、ボタンは ルック / フラッシュ / 撮影補助 / 設定 の4つだけになります。 「プロ」にすると フォーカス が増え、シャッター速度や ISO を自分で決められます。くわしくは 06 へ。

02

撮る

ピントと明るさ

  • 写したいものをタップすると、そこへピントと明るさを合わせます。
  • 長押しすると、ピントと明るさをその状態で固定します。構図を少し動かしてから撮りたいときに使います。
  • 置いたピントの枠は、指でつかんでそのまま動かせます。
  • 撮影のあと、しばらくすると固定は外れて元の追従に戻ります。初期値は3秒で、設定 > 撮影 > 撮影後にAFロックを解除するまで で「解除しない」から30秒まで選べます。
  • 明るさを足したい・引きたいときは、下の帯の露出を開いて「露出補正」を + か − へ動かします。

ズームとレンズ

  • 倍率のスライダーを動かすか、プレビューをピンチします。
  • ダブルタップでも変えられます。押すたびに 1x → 2x → 4x → 1x と一周します。
  • シャッターの右の「1x」ボタンでレンズを切り替えられます。複数のレンズを持つ端末では、倍率に応じて自動でも切り替わります。
  • レンズの倍率を超えたぶんは拡大で補うので、倍率を上げるほど細部は粗くなります。

指でできること（まとめ）

タップそこへピントと明るさを合わせる
長押しピントと明るさを固定する
枠をなぞる置いたピントの枠を動かす
ダブルタップ倍率を 1x → 2x → 4x → 1x と送る
ピンチ倍率を無段階で変える
左右に払うルックを前後に送る（一覧を開かずに色を変えられます）

シャッターを押したあと

暗いところでは、自動で何コマかを続けて撮って重ねます（合成）。 押したあと少しのあいだは、そのまま構えていてください。 重ねる・ぼかす・色を整えるといった処理はすべて端末の中で行うので、保存まで数秒かかることがあります。 端末が熱くなっているときは、写真を確実に残すために重ねる枚数を減らしたり、HDR を止めたりします。 そのときは画面に一言出ます。

手を使わずに撮る

  • セルフタイマーは 撮影補助 > セルフタイマー で 3秒 / 5秒 / 10秒 から。
  • 設定 > 撮影 > 音量ボタン を「シャッター」にすると、音量キーで撮れます（初期値は「使わない」。「ズーム」も選べます）。

動画

  • 撮影補助 > 動画 を ON にすると、シャッターが赤い丸に変わります。
  • 押すと録画が始まり、枠が赤くなって時間が出ます。止めるときも同じボタンです。
  • マイクの許可を出していない場合は、音声なしで録画します（録画自体は止まりません）。

03

撮った写真を見る

シャッターの左にある直前の1枚をタップすると、アプリの中の写真ビューアが開きます。

  • 左右にスワイプで前後の写真へ。ピンチで拡大、ダブルタップで等倍になります。
  • 「撮影情報」で、そのときのルックや露出を見られます。
  • 「他のアプリで開く」で、ギャラリーや編集アプリへ渡せます。
  • 「元画像も保存」を ON にして撮った写真なら、「オリジナルと比較する」でルックや合成をかける前の1枚と見比べられます。
このビューアに並ぶのは、いま入っているこのアプリで撮った写真だけです。 アプリを入れ直すと、それより前に撮った写真はここに出なくなります。写真そのものは端末に残っているので、 端末のギャラリーや Google フォトなどから見てください（保存先）。

04

色を決める

ルック（21種類）

下の帯のルックから選びます。選んだ瞬間にプレビューが変わるので、撮る前に決められます。 プレビューを左右に払っても、順に送れます。

スタンダード / NATURAL / FLAT / SCENERY / PORTRAIT / フィルム / VIVID+ / フード / モノクロ / MONO HIGH / MONO SOFT / MONO GRAIN / ティール / ウォーム / ネガ / クローム / STREET / CINE D / CINE V / CINE SOFT / REC709

一覧の上の「ルックの効き」で、その色をどれくらい強く当てるかを ± で変えられます。 「この色は好きだけど、もう少し薄く」というときに下げてください。 表示モードが「プロ」のときは、その上に彩度も出ます。

使わないルックは 設定 > 画作り で隠せます。払って送るときの一周が短くなります。

仕上げ

下の帯の仕上げには4つあります。どれも動かすとプレビューに出ます。

階調カーブ（DR）初期値 標準
明るいところと暗いところのつなぎ方です。 標準は暗部を持ち上げて明暗差をやわらげる方向、S字はコントラストを上げて黒を沈める方向、 トゥは暗部だけ締めて明るいところは粘らせる形、深黒は黒をいちばん深く置きます。
ボケの量初期値 なし
なし / 弱 / 標準 / 強 / 最強 の5段。奥行きを推定して、ピントの外をぼかします（ボケ）。
明瞭度
質感の立体感です。上げるとものの凹凸が強調され、下げると柔らかくなります。初期値を ±0 として表示します。
シャープ
輪郭のくっきり具合です。初期値を ±0 として表示します。

端末によっては、明瞭度とシャープの強さがプレビューに出ないことがあります（写真には設定どおりに掛かります）。 その端末では、設定 > 画作り に注意書きが出ます。

05

露出・フラッシュ・撮影補助・フォーカス

露出

露出モード
A は端末におまかせ。P もおまかせですが、設定の「ISO上限」や「最低シャッター速度」が効きます。 S はシャッター速度を優先、M はシャッター速度と ISO を自分で決めます。 かんたん・標準の表示では A/P/S/M が画面に出ないので、設定 > 撮影 > 露出モード から変えてください。
露出補正
−3.0〜+3.0 を 1/3 段ずつ。写真を明るくしたいときは +、暗くしたいときは −。M のときは出ません。
シャッター速度 / ISO 感度
シャッター速度は S と M、ISO は M のときだけ出ます。
ホワイトバランス
自動 / 晴天 / 曇天 / 日陰 / 電球 / 蛍光灯。照明の色で写真が黄色や青に寄るときに合わせます。

フラッシュ

OFF / 自動 / 強制発光 / 弱フィル / 常時点灯。弱フィルは一瞬強く光らせるのではなく、 弱く点けたまま撮って、その場の雰囲気を残す使い方です。 端末や前面カメラによっては使えない方式があり、そのときは選べないか OFF に戻ります。 フラッシュを使っているあいだは、ナイトモードと HDR が止まります。

撮影補助

合成初期値 自動
同じ場面を4枚・8枚続けて撮り、位置を合わせて重ねます。重ねるほど暗いところのざらつきが減ります。 自動は暗いときだけ重ねます。×4 / ×8 は明るさに関係なく毎回重ねます。
HDR初期値 OFF
明るさの違う3枚から、白飛びと黒つぶれを抑えた1枚を作ります。空と建物のように明暗差が大きい場面向けです。
セルフタイマー
OFF / 3秒 / 5秒 / 10秒。
構図グリッド・水準器
線と水平の目安を出します。グリッドの種類は 設定 > 表示 で選べます。
動画
写真と動画を切り替えます。

フォーカス（プロ表示のとき）

ピント合わせ
AF（自動）か MF（手動）。MF にすると「ピント距離」が出ます。
ピーキング
ピントが合っている輪郭に色を付けます。MF で合わせるときの目安です。
合焦しないとき
「待たずに撮る」か「合うまで待つ」。設定 > 撮影 の「AFが合わないときの撮影」と同じです。
撮影後にピントを戻すまで（秒）
タップや長押しで決めたピントを、撮影後いつ外すか。0 は外しません。

06

表示モードを変える（かんたん / 標準 / プロ）

撮影画面の上のボタンか、設定 > 表示 > 表示モード（縦持ち） で切り替えます。初めて起動したときのガイドでも選べます。

  • かんたん。ルック / フラッシュ / 撮影補助 / 設定 の4つ。プレビューをいちばん広く使えます。初めての人はここから。
  • 標準（初期値）。上に加えて 仕上げ / 露出。
  • プロ。さらに フォーカス。A/P/S/M、シャッター速度・ISO・ホワイトバランスの現在値が画面に出ます。
変わるのは画面に出す情報の量だけです。 撮影の設定（合成やHDR、画質、ルック）は切り替えても変わらず、写り方も3つとも同じです。 「かんたん」でも、撮影補助から動画まで全部たどり着けます。

07

設定画面（タブごと）

撮影画面の設定を押すと開きます。左に 撮影 / 画作り / ボケ / 表示 / 音 / 保存 / 設定 / アプリ / 開発 の9つのタブが並び、 押したタブの項目が右に出ます。右上の ? を押すと、そのタブで何を決めるのかが出ます。

変えた値はその場で保存され、次に起動したときもそのままです。 露出補正・合成・HDR・フラッシュのように撮影画面でも変えられる項目は、どちらで変えても同じ値です。

下の一覧の「初期値」は、入れた直後の値です。Android 12 以下の端末やメモリの少ない端末では、 動作を軽くするために 合成＝使わない / 画質＝標準 / ボケをプレビューに反映＝OFF から始まります。

◉ 撮影

記録する写真の大きさ、ピント、明るさの決まりごと。

写真の形と画質
アスペクト比初期値 4:3
写真の縦横の比率です。 4:3（標準） / 16:9 / 1:1（スクエア） / シネスコ 2.39:1 / X 1枚投稿（16:9） / X 2〜3枚投稿（8:9） / X 4枚投稿（16:9） X の項目は、X（旧Twitter）に載せる枚数に合わせた比率です。透かしを「写真の下に帯を足す」形で入れると、選んだ比率より縦長になります（保存）。
画質初期値 自動
画素数と JPEG の品質です。数字が大きいほど細かく残り、ファイルも大きくなります。 自動 / 低（3MP・70%） / 標準（8MP・85%） / 高（12MP・92%） / 特高（12MP・95%） / 最高（12MP・100%） / 最大解像度（実験的・処理が重い） 迷ったら「自動」のままで大丈夫です。
画質：最大解像度（実験的）
センサーが持つ最大の画素数で撮ります。Android 12 以上で、端末とレンズが対応しているときだけ使えます（Android 11 では選択肢に出ません）。 処理が重いぶん、次の制限があります。
  • 露出は端末にまかせます。M（マニュアル）や「合焦したときだけ撮る」を選んでいると、その1枚は通常の画質で撮ります（画面にそう出ます）
  • 暗いときに自動で重ねる合成は働きません
  • ピーキングと RAW(DNG) は使えません。フラッシュも方式によっては OFF に戻ります
  • 対応していないレンズに切り替えたときは、通常の画質で撮ります
シャッターの優先度初期値 速度優先
押した瞬間と写る瞬間のずれをどう扱うかです。 速度優先（押した瞬間を撮る・推奨） / 低遅延 / 画質優先（多枚合成・ラグあり） 速度優先に対応していない端末では、自動で「低遅延」になります。 一部の端末では速度優先のときに写真全体が緑になることがあり、アプリが見つけると撮り直します。何度も続くときは「低遅延」にしてください。
端末の画像処理（拡大時の描写）初期値 標準
端末がかけるノイズ低減と輪郭強調の強さです。 素の描写（ノイズ増・上級者） / 標準（推奨） / なめらか 素の描写は端末の処理を切って、アプリ側で控えめにシャープを掛けます。拡大したときに細部が塗り絵のようになりにくい代わりに、ざらつきは増えます。 なめらかは端末の処理を丁寧なほうで掛けます。
露出（明るさの決め方）
露出モード初期値 S
A（おまかせ・推奨） / S（シャッター速度優先） / M（マニュアル） / P（おまかせ・ISO上限が効く） それぞれの意味は 05 を見てください。端末が手動の露出に対応していないときは A で動きます。
露出補正初期値 ±0.0
−3.0〜+3.0 EV。撮影画面の露出補正と同じ値です。
M：シャッター速度 / M：ISO / M：フォーカス
M を選んだときに使う値です（初期値は 1/125・ISO 100・AF）。端末が対応していない範囲は、撮影画面へ戻ったときに端末の範囲へ収めます。
逆光・暗い被写体を自動で持ち上げる初期値 ON
露出が A のときだけ効きます。画面の中央とピント位置を重く見て、主役が背景より暗いときに明るさを補います（最大 +1.3段）。白飛びが広いときは逆に抑えます。OFF にすると端末まかせに戻ります。

暗くなったときの順番（P と S のとき）

暗くなるにつれて、まずシャッター速度を「最低シャッター速度」に置いたまま ISO を「低ノイズ優先ISO」まで上げます。 次にシャッター速度を「上限」まで遅くして粘り、それでも足りなければ ISO を「ISO上限」まで上げます。 下の4つはこの順番の区切りを決める項目で、A（おまかせ）のときは効きません。

SS優先で確保する最低シャッター速度初期値 1/125
1/60 / 1/125（推奨） / 1/250 / 1/500 / 1/1000 速くするほどブレに強くなり、そのぶん ISO が上がってざらつきやすくなります。子どもやペットなら 1/250〜1/500 が目安です。
暗所で伸ばしてよいシャッター速度の上限（単写）初期値 1/60
1/125（ブレに最も強い） / 1/60（推奨） / 1/30 / 1/15（三脚向け） 合成しないときに、どこまで遅くしてよいか。遅くするほどざらつきは減り、手ブレや被写体ブレは出やすくなります。
同・多枚合成のとき初期値 1/30
1/125 / 1/60 / 1/30（推奨） / 1/15（暗所に最も強い・三脚向け） 合成するときは位置合わせでブレを吸収できるので、単写より遅くまで許せます。三脚なしの 1/15 は、動くものがブレることがあります。
ISO上限（ノイズ許容）初期値 ISO 3200
ISO 400 / 800 / 1600 / 3200（推奨） / 6400 / 制限しない 下げるとざらつきは減りますが、とても暗い場面では写真も暗くなります。
低ノイズ優先ISO初期値 ISO 400
ISO 100 / 200 / 400（推奨） / 800 / 1600 ここを超える前に、シャッター速度を遅くして粘ります。
ピント
AF動作初期値 AFC
AFC（動きものに追従・推奨） / AFS（合焦したら固定） 動くものは AFC。止まっているものをじっくり撮るなら AFS でも。
AFエリアの大きさ初期値 1点
1点（スポット） / 小さめの枠 / 少し大きめの枠 / もう少し大きめの枠 タップした場所のどれくらいの範囲でピントを探すか。小さいものを狙うなら1点、模様の少ないものは枠を大きくすると合いやすくなります。
AFが合わないときの撮影初期値 合焦を待たずに撮る
合焦を待たずに撮る（従来どおり・推奨） / 合焦したときだけ撮る 「合焦したときだけ撮る」にすると、ピントが決まらなかった回は撮影を中止します。無地の壁や暗すぎる被写体では、待たずに撮るほうが使いやすいです。
撮影後にAFロックを解除するまで初期値 3秒
解除しない（ロックしたまま） / 1秒 / 2秒 / 3秒 / 5秒 / 10秒 / 30秒 同じ場所で何枚も撮るなら長めに。
合成・HDR・フラッシュ・そのほか
多枚合成スタック初期値 自動
自動（暗いときだけ・推奨） / 使わない / 常に ×4 / 常に ×8 撮影補助の「合成」と同じ値です。枚数が多いほどざらつきは減り、保存までの時間は長くなります。
HDR初期値 OFF
撮影補助の HDR と同じ値です。
セルフタイマー初期値 OFF
OFF / 3秒 / 5秒 / 10秒。
フラッシュ初期値 OFF
OFF / 自動 / 強制発光 / 弱フィル / 常時点灯 端末・前面カメラ・最大解像度で使えない方式は、撮影画面へ戻ったときに OFF へ戻ります。
弱フィルの光量初期値 最小
最小 / 25% / 50% / 75% / 最大 フラッシュを「弱」にしたときの明るさ。光量の調整に対応していない端末では、最小のまま点きます。
音量ボタン初期値 使わない

08

場面別のおすすめ

どれも「まずはこう」という出発点です。撮ってみて、好みで戻してください。

暗い室内・夜景

  • 撮影補助の合成は「自動」のままで。暗いと判断すると自動で重ねます。
  • 押したあと、保存が終わるまで構えたままにします。ひじを机に置くだけでもブレが減ります。
  • 三脚や台に置けるなら、設定 > 撮影 の「同・多枚合成のとき」を 1/15 に。ざらつきがさらに減ります。
  • 夜の雰囲気を残したいときは、露出補正を − に振ります。明るく持ち上げすぎないほうが夜らしく写ります。

子ども・ペット・乗りもの（動くもの）

  • 設定 > 撮影 の「最低シャッター速度」を 1/250〜1/500 に（露出モードが S か P のときに効きます）。
  • AF動作は AFC（初期値）のまま。
  • 合成と HDR は複数コマを重ねるので、速く動くものはブレたり二重に写ったりすることがあります。確実に止めたいときは「使わない」に。

逆光（窓際・夕方の空を背にした人）

  • 主役が暗いときは、主役をタップしてから露出補正を + へ。
  • 露出モードを A にすると「逆光・暗い被写体を自動で持ち上げる」（初期値 ON）が効きます。
  • 空の色も残したいときは HDR を ON に。

料理

  • ルックは「フード」から。
  • お店の照明で全体がオレンジに寄るときは、ホワイトバランスを「電球」に。雰囲気を残したいなら自動のままでも。
  • 寄って撮るなら、ボケを「弱」にすると背景だけが少しやわらぎます。

自撮り・人物

  • 「顔にピント・露出を合わせる」は初期値で ON です。
  • ルックは PORTRAIT、ボケは「弱」か「標準」から。髪の境目が気になったら弱めてください。
  • セルフタイマーや、音量ボタンのシャッターも使えます。

拡大して細部まで見たい

  • 画質を「最高」に。対応する端末（Android 12 以上）なら「最大解像度」も選べます（制限は 撮影タブ）。
  • 端末の画像処理を「素の描写」にすると、細部が塗りつぶされにくくなります。そのぶんざらつきは増えます。
  • 望遠で画質が粗いときは、1x のまま合成で撮って、あとから切り出すほうがきれいな端末もあります。

電池を持たせたい・動作が重い・熱くなる

  • 撮影補助の合成を「使わない」、HDR を OFF に。
  • ボケを「なし」にし、設定 > ボケ の「ボケをプレビューに反映」を OFF に。
  • 設定 > 表示 の「プレビューを実際の写真と同じ色にする」を OFF に。
  • 画質を「標準」に下げる。

処理が減るぶん、保存までの時間も短くなります。

SNS に載せる

  • アスペクト比に X 用の比率があります（1枚 / 2〜3枚 / 4枚）。
  • 透かしを入れるなら 設定 > 保存 > 透かし を ON に。比率を崩したくなければ「透かしの帯を写真の中に重ねる」も ON に。
  • 位置情報を記録している写真は、送った相手も位置を見られます。気になるときは記録を OFF にしてください。

あとで自分で仕上げたい

  • 「元画像も保存」を ON にすると、ルックをかける前の JPEG も残ります。
  • RAW に対応した端末なら「RAW(DNG)も保存」。DNG は RAW を開けるアプリで扱えます。

09

撮った写真はどこに入るか

  • 写真は端末の Pictures/AKU CAM フォルダに、AKUCAM_日付_時刻.jpg という名前で入ります。ギャラリーや Google フォトなど、ほかのアプリからもそのまま開けます。
  • 動画は Movies/AKU CAM フォルダに入ります。
  • 「元画像も保存」が ON なら、同じフォルダに _orig 付きの JPEG が、RAW が ON なら .dng が並びます。
  • アプリの中の写真ビューアに出るのは、いま入っているこのアプリで撮った写真だけです。入れ直す前の写真は、端末のギャラリーから見てください。
  • アプリを削除しても、撮った写真は端末に残ります。
  • 位置情報を ON にした場合だけ、写真の EXIF に位置が入ります。アプリから外部へ送ることはありません。

うまくいかないとき

よく聞かれることは よくある質問 にまとめました。 英語で表示される、写真が緑になる、画面が真っ黒、シャッター音、透かしなども、そちらにあります。

カメラが開かない

「カメラを開始できません」と出たときは、その画面のセーフモードで起動を押してください。 重い設定をいったん切って、カメラをつなぎ直します。設定画面からなら 設定 > 開発 > カメラを既定設定で起動（セーフモード） です。

落ちた・写真が保存されなかった

設定 > 開発 > 診断レポート から、そのときの状況を書き出せます。 写真そのものや位置情報は入りません。落ちた直後のものがいちばん参考になります。 設定 > アプリ > メールで連絡する から送ると、バージョンと端末名が自動で入ります。 メールアドレスは sakego.syasai@gmail.com です。「何をしたら起きたか」を一言添えていただけると助かります。

設定をいじりすぎて分からなくなった

すべてを最初に戻すボタンはありません。カメラまわりの重い設定だけなら、上のセーフモードで戻せます。 いろいろ試す前に 設定 > 設定 > 設定をエクスポート で控えを取っておくと、あとで同じ設定に戻せます。
