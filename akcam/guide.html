Guide

操作説明

難しい設定をしなくても、シャッターを押すだけで写真になります。 このページは「もう少し踏み込みたくなったとき」に読むためのものです。

01

撮影画面の見かた

  1. 情報帯 — シャッター速度・ISO・露出補正・ホワイトバランスと、いま効いているルック / 合成 / HDR / ボケ / 透かし / 画質。設定を開かなくても、いまの状態がここで全部わかります。
  2. プレビュー — 仕上がりに近い絵が出ます。ルックやボケを変えると、この場で見た目が変わります。ピントを合わせたいところをタップすると、そこにピントと露出を合わせます。
  3. ルック — 色の方向性を選びます（21種類）。
  4. 撮影補助 — 合成・HDR・セルフタイマー・構図グリッド・水準器・動画。
  5. 設定 — 画質や保存形式など、じっくり決めるものはこちら。
  6. 直前の1枚 — タップすると撮った写真を見られます。左右になぞると前後の写真へ。
  7. シャッター — 押すだけ。動画モードのときは赤い丸に変わります。
表示モードを「かんたん」にすると、④⑤とルック / フラッシュの4つだけになります。 「プロ」にすると、露出やフォーカスの項目が増えます。

02

撮る

ピントと明るさ

  • 写したいものをタップすると、そこへピントと測光を合わせます。
  • 合わせた状態のままにしたいときは、そのまま撮影してください。撮影のあと数秒で自動的に解除され、元の追従に戻ります（設定 > 撮影 > 撮影後にAFロックを解除するまで で 0〜30秒）。
  • 明るさを足したい・引きたいときは、rail の露出から ± で調整します。

ズーム

  • プレビュー下の倍率スライダーを動かすか、プレビューをピンチします。
  • ダブルタップでも変えられます。押すたびに 1x → 2x → 4x → 1x と一周します。
  • 端末が複数のレンズを持っている場合、倍率に応じて自動で切り替わります。

指でできること（まとめ）

タップそこへピントと明るさを合わせる
長押しそこでピントを固定する（AFロック）
ダブルタップ倍率を 1x → 2x → 4x → 1x と送る
ピンチ倍率を無段階で変える
左右に払うルックを前後に送る（一覧を開かずに色を変えられます）

手を使わずに撮る

  • セルフタイマー: 撮影補助 > セルフタイマー（3 / 5 / 10秒）。
  • 音量ボタン: 設定 > 撮影 > 音量ボタン を「シャッター」にすると、音量キーで撮れます（既定は「使わない」。「ズーム」も選べます）。

動画

  • 撮影補助 > 動画 を ON にすると、シャッターが赤い丸に変わります。
  • もう一度押すと録画が始まり、枠が赤くなって時間が出ます。停止も同じボタンです。
  • マイクの許可を出していない場合は、音声なしで録画します（録画自体は止まりません）。

03

色を決める

ルック（21種類）

rail のルックから選びます。スタンダード・FLAT・風景・ポートレート・フィルム・モノクロなど。 選んだ瞬間にプレビューが変わるので、撮る前に決められます。

上の「ルックの効き」で、その色をどれくらい強く当てるかを ± で変えられます。 「この色は好きだけど、もう少し薄く」というときに使ってください。

仕上げ

rail の仕上げでは、彩度・明瞭度・シャープを ±0 を基準に微調整できます。 ここも、動かすとプレビューに出ます。

04

撮影補助 — 合成・HDR・タイマー

合成

同じ瞬間を4枚・8枚連続で撮り、位置を合わせて重ねます。 重ねるほど暗いところのザラつきが減ります。自動にしておくと、 暗さに応じて枚数を決めます。

端末が熱いとき・電池が厳しいときは、枚数を自動で減らして写真が失われないようにします。

HDR

明るさの違う3枚から、白飛びと黒つぶれを抑えた1枚を作ります。

そのほか

  • セルフタイマー: OFF / 3秒 / 5秒 / 10秒
  • 構図グリッド: 三分割などの線を出す
  • 水準器: 傾きを見る
  • 動画: 写真 ⇄ 動画の切り替え

05

表示モードを変える（かんたん / 標準 / プロ）

設定 > 表示 > 表示モード（縦持ち） で切り替えます。

  • かんたん — ルック / フラッシュ / 撮影補助 / 設定 の4つ。初めての人はここから。
  • 標準 — 上に加えて 仕上げ / 露出。
  • プロ — さらに フォーカス。A/S/M や細かな値も画面に出ます。
変わるのは画面に出す情報の量だけです。 撮影の設定（合成やHDR、画質）は切り替えても変わりません。 「かんたん」でも、撮影補助から動画まで全部たどり着けます。

07

撮った写真はどこに入るか

  • 写真は Android の写真（ギャラリー）に、動画はMoviesに保存されます。ほかのアプリからもそのまま開けます。
  • 「元画像も保存」を ON にすると、現像前のJPEGも一緒に残ります（写真一覧には出さず、ファイルとして残ります）。
  • RAW(DNG) に対応した端末で ON にすると、1回の撮影で DNG と JPEG の2つが保存されます。
  • 位置情報を ON にした場合だけ、写真のEXIFに座標が入ります。アプリから外部へ送ることはありません。

08

うまくいかないとき

暗いところで撮ると時間がかかる

合成を「自動」にしていると、暗いほど多くの枚数を重ねます。その分だけ保存までに時間がかかります。 早さを優先したいときは、撮影補助 > 合成 を「なし」にしてください。

ピントが合わないまま撮れない

設定 > 撮影 の 「AFが合わないときの撮影」を「合焦を待たずに撮る」にすると、 ピントが決まらなくてもシャッターが切れます（こちらが既定です）。逆に「合焦したときだけ撮る」にしていると、 決まらなかった回は撮影を中止します。 コントラストの少ない壁や、暗すぎる被写体ではこちらが便利です。

落ちた・写真が保存されなかった

設定 > 開発 > 診断レポート から、そのときの状況をファイルに書き出せます。 写真そのものや位置情報は入りません。落ちた直後のものが一番参考になります。 sakego.syasai@gmail.com まで、端末名と「何をしたら起きたか」を添えて送っていただけると助かります。

設定をいじりすぎて分からなくなった

設定 > 設定 から初期化できます。書き出しておけば、あとで同じ設定に戻せます。
