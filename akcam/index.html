About

"撮って出し"の写真を楽しもう

スマートフォンで撮影した写真が当たり前のように加工される現代にアンチテーゼを唱えたい。 その時その場の空気感や立体感といった本当の見た景色を残す、それが写真だと感じています。 私はその哲学のもと、スマートフォンという現代人が一番写真を撮るデバイスにおいて、 ピュアな撮影体験を得られるカメラアプリをつくりました。 このアプリでは、一眼レフやミラーレスカメラのような本格的な機能も有しながら、 簡単に皆さんの記憶に残る1枚を撮影することができます。さあ、感動の瞬間をメモリに残しましょう。

地球上どこでも等しい撮影体験が得られるように、このアプリはインターネットに接続する必要はありません。 また広告もありません。開発者に何らかのデータが送られることはありません。あるのは撮影に必要な機能だけ。 思う存分楽しんでください。本来の写真を楽しむ時間です。

スタンドアロン

通信は発生しません。ご自身のスマートフォンが動作する環境であれば、地球上どこでも同様に動作します。

21種類のルック

スタンダード / 風景 / ポートレート / フィルム / モノクロ など。ルックを選択するとプレビュー画面に反映されます。

深度ボケと多枚合成

奥行きを推定して背景をぼかすことができます（ただし機能的な限界もあり、うまくいかない場面もあります）。端末スペックに応じて4枚・8枚を合成し、ノイズリダクション・高画質化することができます。古めの端末だと純正アプリより良い画質で撮ることが可能かもしれません。

かんたん / 標準 / プロ

撮影スタイルは3種類から選択することができます。シンプルな見た目がお好みの方はかんたん。細かいパラメータ調整をしながら撮りたい方はプロ。それ以外の方は標準から始めてみてください。あとからUIを変更することが可能です。

撮ったままも、やっぱり現像したい方にも

ルック適用前のJPEG、対応端末であればRAW(DNG形式)を同時に保存することも可能です。

透かし

日付・端末名・署名などを入れたオリジナルフレームを写真に付けられます。もちろんオフにすることも可能です。自由記述欄を使って、思い出のシーンにコメントを入れることも可能です。

Spec

できること

撮影露出 オート / 絞り優先 / シャッター優先 / マニュアル、露出補正、ホワイトバランス、タップAF、AFロック、セルフタイマー、音量ボタンでシャッター
画づくり21種類のルック、効きの強さ、彩度・明瞭度・シャープの微調整、HDR、4枚 / 8枚の合成
ボケ奥行き推定による背景ぼかし（端末内推論）。強さを段階で調整
保存現像済みJPEG、元画像JPEG（任意）、RAW/DNG（対応端末のみ・任意）、動画
表示かんたん / 標準 / プロ の3段階、構図グリッド、水準器、ピーキング、縦横の自動追従
その他透かし（ロゴ・署名・日付・端末名）、写真へのGPS記録（任意）、診断レポートの書き出し
動作環境Android 11（API 30）以上。ボケや夜景など一部の機能は端末の対応状況によります
通信なし（インターネット権限を宣言していません）
端末によって使える機能が変わります。たとえば RAW(DNG) や 夜景モード、最大解像度での撮影は、 その端末のカメラが対応している場合だけ有効になります。対応していない端末では、 同じ操作でも通常の撮影として保存されます。
